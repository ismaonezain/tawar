How this demo works. The sellers are simulated agents (three personas with hidden floor prices), because Tawar never touches real money or real marketplaces in a demo. The buyer negotiates with SERV Reasoning, and its ceiling is enforced by a separate code module that re-checks every proposed deal before it can close. The model can agree to anything, only the code can say yes to a payment.
